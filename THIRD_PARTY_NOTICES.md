# Third-party notices

PDF Chef includes the third-party components below. Each entry gives the version that ships, the licence, the copyright line and the project page. The full text of every licence follows the tables.

This file is generated by `node scripts/generate-third-party-notices.mjs` from `services/legal/thirdPartyComponents.json` and `services/legal/licenseTexts.json`. The Settings > Open-source licenses page in the app shows the same data. Edit those two files, not this one.

## What is listed

- **JavaScript packages (79)**: the production dependency tree in `package.json` at the versions in `package-lock.json`. Development tools, type-only `@types/*` packages and the Node.js-only `@napi-rs/canvas` binaries are not shipped and are not listed.
- **Bundled assets and embedded libraries (26)**: WebAssembly modules, fonts, character maps and trained data that the app serves, including the libraries compiled into those modules.
- **Android libraries (100)**: the resolved runtime dependencies of the release build of `android/app`, with the versions Gradle selected.

Where a package offers a choice of licences, the entry names the one the app uses and says so in its note. Google Play services, Play Core and ML Kit are proprietary Google libraries rather than open source; they are listed for completeness and their terms are linked in the licence section.
